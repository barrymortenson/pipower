# PiPower

Raspberry Pi-based power outage monitoring system using off-the-shelf UPS devices (CyberPower, ADP, Goldemate).

## Tech Stack
- Laravel/PHP with SQLite
- Vue.js 3 with Tailwind CSS
- pnpm for package management
- Pest for PHP testing
- Laravel Prompts (for CLI interfaces)

## Key Features
- UPS power status monitoring via USB (NUT)
- Initial setup via WiFi AP mode or alternative configuration method
- Web UI or CLI for configuration (WiFi, static IP, etc.)
- Notification system (email, Plivo SMS)
- Status page/API for monitoring tools (e.g., Uptime Robot)
- Deployable Raspberry Pi image (headless, compressed)

## Development
- Run `composer run dev` for dev services, then `php artisan serve` or use Laravel Valet
- Base image: Raspberry Pi OS Lite (headless)
- Use PiShrink for creating distributable images
